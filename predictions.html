三级频率阶梯：从哈勃球到正四面体结

待验模型底座极简：宇宙只有以太的不同结构，以及以太的运动。人类所称的不同物质乃至碳基人类自身，皆归于此。基础以太结构是正四面体，其余一切物质结构皆由正四面体打结而成。

每个以太结构周围裹着一片回流经结的以太空间。基础以太为最小单元，频率约 4.3× 10102 Hz，达质子频率的 1079 倍，穿透一切结构：沿拇指轴穿进结，在四指平面按右手逆时针以光速螺旋发散，形如磁偶极子的力线。结即流里持续存在的漩涡之形，以太不生不灭，连续性自动满足；每个结随底流整体推进、加速度相同，引力场内不同材质同速下落的等效原理由此落定。结的频率 f = mc2/h = c/λC，对应每秒光速以太穿过该结自身康普顿波长的次数。

二〇二六年三月三日，张祥前写出把整个哈勃球当作单一德布罗意波包的归一化方程 4π2 r3 c2 / (T2 G h ν) = 1。按开普勒第三定律取 r = c/H、T = 2π/H，结合 Mc2 = hν，得 ν = c5/(hGH) = 2πν以太 = 2.725× 10103 Hz。路谦和与张祥前据此预注册中间级定律——普朗克频率是宇宙膨胀率 H 与以太频率 ν以太 的几何平均，任一时期 t 恒有：

ν以太(t) · H(t) = νP2 = 8.715× 1084 Hz2,      ℏ · G = (c5) / (4π2 · ν以太(t) · H(t))

这道等式立起一架三级频率阶梯。顶层一级为宏观宇宙层：膨胀率 H 在哈勃常数中值 62.0 km·s-1·Mpc-1 下为 2.009× 10-18 s-1，预注册区间 61.8–63.5 对应 2.003× 10-18–2.058× 10-18 s-1。中间一级卡在人类观测边界：普朗克频率 νP = √(c5/ℏ G)/2π = 2.952× 1042 Hz，对应普朗克质量 21.76 微克；下段阶梯几何中点频率 √(HνP) = 2.435 THz，区间 2.43–2.46 THz。底层微观以太底色：以太频率 ν以太 = νP2/H = 4.337× 10102 Hz，区间 4.235× 10102–4.351× 10102 Hz。每层跨度倍数 N = νP/H = 1.469× 1060，区间 1.435× 1060–1.474× 1060。

宇宙演化分两段。早期非匀速段自宇宙诞生至 39.12 亿岁（区间 36.41–39.50 亿岁），高温辐射与更小单元物质结构剧烈碰撞、并合、打结；其中 ν以太 = 1096 Hz 与 1.51× 1096 Hz 分别对应宇宙年龄 1,866 岁与 2,833 岁。转折出在距今 99.00 亿年前，区间 98.93–99.33 亿年前，红移 zs = 1.686（区间 1.669–1.817；声学角基准 zs = 1.721 对应 38.37 亿岁、尺度比 1+zs = 2.721 ≈ e）。大尺度星系结构稳定成形，十二维相空间每维十个数量级的以太场压抵消进入 N-2≈ 2.2× 10-120 随机稳态，膨胀率转入匀速滑行 H(z) = H0(1+z)。此后 99.00 亿年，以太频率由 1.615× 10102 Hz 随宇宙年龄线性增长至今日 4.337× 10102 Hz，膨胀率反比下降，乘积锁定在 8.715× 1084 Hz2，确保 ℏ 与 G 不随时间漂移，满足月球激光测距 |Ġ/G| < 1.5× 10-13/年。两段相加 138.12 亿年（预注册表按 H0 t0 = 0.876 取整记当前宇宙年龄中值 138.2 亿年）。

如果数值对了，它替人类打开全领域科技的大门；如果数值不对，它替后来人封死一条走不通的岔路，两样都算数。

二十一点八微克与老人的时间账：现在重视很重要

判决最快的一刀在实验室台面上的 P6 与 P6.1。按公理第一、第三、第四条，被测物质、探测光、真空与仪器，连同观察者眼睛与身体（体重频率 F = M人c2/h）、实验室建筑及周围重型设备，共同叠加成观测集体频率场。被测模式有效质量进入 21.8 ± 0.3 微克窗口时，观测集体把人类观测层卡在普朗克频率采样门限上，场压换能脱钩：经典光学散射、力学响应与非经典量子猫态同时跌至窗外基准的 1\% 以下，移出窗口立即恢复；更换实验室、启停周围大型设备或改变近场观察者体重配置，盲区中心与宽度可复现偏移。二〇二三年 Bild 等人的猫态实验已走到 16.2 微克，完成 21.8 微克门槛的 74\%，只差最后 5.6 微克的连续扫描。

这项实验容不得顺其自然慢慢排期。翻开前四页便能算清：法拉第线圈一八三一年跳了一下，到洞庭湖边九岁女孩的十五瓦灯泡亮起隔了一百五十多年；哈伯一九〇九年在实验台合成氨，六十七年后尿素才撒进一九七六年的杂交稻田；詹纳一七九六年种牛痘，一百八十四年后的一九八〇年才根除天花。从实验室验完真伪到开发出进医院、进家庭的产品，工程转化周期漫长，早一天动手检验才抢得出窗口。

这笔时间账连着人类的每一位成员。人类终将老去，眼下年轻的人，家里多半也有父母或年迈长辈。现在引起重视、尽快完成实验检验并启动转化，快的话，家里的老人还用得上；慢的话，今后自己老了也能用得上。

关于此页的推演，欢迎具备相关测量条件的物理实验室独立复核、设计实验检验这套以太频率公式是否成立；无论证实或证伪，实验读数都是对这一页最踏实的交代。
